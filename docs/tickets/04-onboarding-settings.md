# 04: [M2·가원] 온보딩과 설정 (연령 구분·보호자)

**GitHub:** [#4](https://github.com/gawounnx/Scamshield-NULLSHIFT/issues/4)

**담당:** 차가원 (프론트: 화면, M2 보호자 알림, 배포, 영상)

## What to build

처음 온 사용자가 1분 안에 온보딩을 끝내요. 연령 구분을 버튼 하나로 고르고(생년월일 입력 없음), 보호자의 이름, 번호, 관계(부모, 자녀, 기타)를 받아요. 정보는 기기에만 저장하고 로그인은 없어요. 설정 화면에서 연령 구분과 보호자를 바꿀 수 있어요.

연령 규칙(SPEC.md): 미성년 사용자(만 19세 미만)는 보호자 필수, 고령 사용자(만 60세 이상)는 보호자 지정 권장, 20–59세는 선택이고 이유를 묻지 않아요.

## Acceptance criteria

- [ ] 첫 실행 시 온보딩이 나오고, 끝나면 홈으로 가요. 다시 열면 온보딩을 건너뛰어요
- [ ] 미성년 사용자는 보호자 없이 온보딩을 끝낼 수 없어요
- [ ] 고령 사용자에게는 자녀를 보호자로 지정하라는 권유가 나오지만 건너뛸 수 있어요
- [ ] 20–59세는 보호자 없이 바로 끝낼 수 있어요
- [ ] 설정에서 연령 구분과 보호자를 바꾸면 바로 반영돼요
- [ ] 보호자 정보는 서버로 보내지 않아요
