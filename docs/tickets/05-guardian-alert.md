# 05: [M2·가원] 보호자 알림 공유

**GitHub:** [#5](https://github.com/gawounnx/Scamshield-NULLSHIFT/issues/5)

**담당:** 차가원 (프론트: 화면, M2 보호자 알림, 배포, 영상)

## What to build

보호자가 있는 사용자가 위험 이상 판정에서 [보호자에게 알리기]를 누르면, 보호자 알림이 공유 창으로 열려 카카오톡·문자 등 평소 쓰는 앱으로 보낼 수 있어요. 사용자가 보내기를 누르기 전에는 아무것도 전송되지 않아요.

보호자 알림 내용은 위험 등급, 사기 유형, 요약이에요. 원문은 기본으로 빠지고, 사용자가 체크했을 때만 텍스트로 붙어요. 공유 창(Web Share API)을 지원하지 않으면 `sms:` 링크로, 그것도 안 되면 클립보드 복사로 넘어가요. 카카오 SDK와 서버 발송은 쓰지 않아요.

## Acceptance criteria

- [ ] 위험·매우 위험 판정에서만 [보호자에게 알리기] 버튼이 보여요
- [ ] 보호자가 없으면 버튼이 보이지 않아요
- [ ] 공유 내용에 위험 등급, 사기 유형, 요약이 들어가고 원문은 기본으로 빠져 있어요
- [ ] 원문 포함을 체크하면 원문 텍스트가 붙어요
- [ ] Web Share 미지원 환경에서 `sms:` 또는 복사로 대체돼요
- [ ] 실제 폰에서 공유 창이 열리고 카카오톡이 보여요(데모 시나리오 3)
